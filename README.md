# Уборка

Веб-приложение для телефона (PWA): уборка по методике профессионалов, шаг за шагом,
под то время, которое есть. Один пользователь, данные хранятся только на телефоне.
База задач взята из документа «База знаний: уборка по комнатам».

## Как устроено

| Файл | Что внутри |
| --- | --- |
| `js/data.js` | Зоны и ~90 задач: частота, минуты, порядок, подготовка, подсказки, предупреждения |
| `js/logic.js` | Чистая логика: срочность, сборка уборки под бюджет (вся квартира или одна комната), свои дела, отпуск, статистика |
| `js/store.js` | Сохранение в `localStorage`, резервная копия в файл и обратно |
| `js/app.js` | Интерфейс: «Сейчас», «Дом», «Настройки», режим уборки |
| `sw.js` | Офлайн-кэш. При изменении файлов поднимать `VERSION` |
| `tools/make-icons.mjs` | Рисует иконки без внешних библиотек |

Правила сборки уборки (`buildSession`):
1. Срочность = прошло дней ÷ частота. «Пора» — от 0,85.
2. Берутся самые срочные задачи, пока влезают в бюджет. Срочность ограничена 2,
   гигиена (`hyg`) при просрочке идёт первой. Если срочное кончилось — добираются
   задачи со срочностью от 0,6.
3. Дела в комнатах, которые уже в плане, получают бонус — меньше беготни.
4. Порядок: сначала все подготовки (средство действует, пока делаешь другое),
   потом зоны от дальней к выходу, внутри — сверху вниз, пол — общей волной в конце.

## Запуск и проверка

```bash
npm test
```

Локально: `python -m http.server 8767` в этой папке, открыть http://localhost:8767.

- [x] Этап 1 — ядро: база задач, срочность, режим уборки с подготовками и ожиданием,
      зоны, частоты, домохозяйство, отпуск, копия, офлайн, иконки
- [x] Этап 1.5 «Уют» — знакомство с домом, питомцы с именами (лоток, миски, лежанки, шерсть),

      тихий фон, короткие уборки в 1–2 комнатах, тёплая палитра «Вечерняя лампа»
- [x] Этап 1.6 — свои дела (добавить, изменить, удалить, «нужно уже сейчас») и уборка одной комнаты
- [x] Этап 1.7 — второй круг СДВГ-теста: кнопка «Начать с малого», встреча после перерыва (дни и посреди уборки), короткие уборки без экрана корзинки, поиск дела в комнатах, честные минуты, автообновление версии
- [x] Этап 1.8 — утренние и вечерние мелочи (ритуалы по шагам, перенос дела утро↔вечер), напоминания через календарь телефона (.ics, без сервера), заметки «что неудобно» (✎ на любом экране, копирование одной кнопкой)
